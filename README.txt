# 🎂 Felicitación para Moisés Abraham — 17 años

Esta carpeta contiene una felicitación web editable y lista para subir a GitHub Pages.

## 📸 Cambiar las fotos
1. Entra en la carpeta `fotos`.
2. Sustituye:
   - `foto1.jpg`
   - `foto2.jpg`
   - `foto3.jpg`
   - `foto4.jpg`
3. Mantén esos nombres para no modificar el código.
4. Puedes usar JPG, PNG o WebP; si cambias la extensión, también cambia el nombre en `index.html`.

## 🎵 Añadir tu música
1. Coloca un archivo MP3 dentro de la carpeta `musica`.
2. Llámalo `cancion.mp3`.
3. Al pulsar **ABRIR MI SORPRESA**, la música intentará comenzar automáticamente.
4. Si tu canción tiene otro nombre, cambia `musica/cancion.mp3` en `index.html`.

## ✏️ Cambiar textos
Abre `index.html` con un editor de texto y busca los comentarios:
- `EDITA ESTE MENSAJE`
- `EDITA LA FIRMA`

Ahí puedes cambiar la felicitación y quién firma.

## 🌐 Subirla a GitHub Pages
Sube `index.html`, `style.css`, `script.js` y las carpetas `fotos` y `musica` a tu repositorio.
Después activa GitHub Pages desde Settings → Pages → Deploy from a branch → main → /(root).

No necesitas instalar nada para verla: abre `index.html` en un navegador.
